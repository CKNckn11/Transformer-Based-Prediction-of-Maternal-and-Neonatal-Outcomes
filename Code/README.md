# Code

This directory contains the organized analysis and figure-generation code for the maternal and neonatal outcome prediction project.

## Folder structure

- `Figure1/`: gestational age plotting and pregnancy subtype boxplot code.
- `Figure2_3_4/`: Manhattan plot code for the GWAS results shown in Figures 2, 3, and 4.
- `Figure5/`: model 1 code, diagnostic metric plotting, and SNP SHAP lollipop plotting.
- `Figure6/`: model 2 code, diagnostic metric plotting, and SNP SHAP lollipop plotting.
- `Supplementary_Figures/`: supplementary QQ plot, locuszoom plot, and extended data table scripts.
